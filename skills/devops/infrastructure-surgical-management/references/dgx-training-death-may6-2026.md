## Diagnosis

OOM during `model.save_pretrained()` at step 500 boundary:

1. Training continuously uses 85.5GB/130GB GPU
2. `save_pretrained()` needs additional memory to serialize 5.1B LoRA weights
3. Combined usage exceeds 130GB → OOM killer sends SIGKILL
4. Process dies mid-write → log truncated, checkpoint directory created but weights never written

## Lessons

1. **Checkpoint integrity ≠ checkpoint existence** — A directory with only README.md is a FAILED save, not a valid checkpoint
2. **OOM at save boundaries is common** — save_pretrained is memory-intensive; plan for it
3. **Debug log lines are not progress indicators** — "Skipping log for step N" is normal; the summary line with Loss is the real indicator
4. **GPU [N/A] after process death** — Usually means the process released the GPU cleanly (not a driver crash)
5. **490 steps ≈ 4 hours lost** — Acceptable. Don't over-engineer recovery for a 12% progress loss

## What Happened (Post-Mortem)

At step ~500, training called `model.save_pretrained()` while GPU was at 85.5GB/130GB. The save operation requires extra memory to serialize 5.1B LoRA weights — this pushed it over the edge and OOM-killed the process.

The checkpoint directory `checkpoint_step_500/` was created but contains only `README.md` (auto-generated by PEFT). No adapter weights or optimizer state were saved.

## Fixes Applied (May 6, 11:40 UTC)

1. **save_every = 1000** — Less frequent saves reduce OOM exposure
2. **4-phase CPU offload save:**
   - Phase 1: `empty_cache()` + `gc.collect()` + `synchronize()`
   - Phase 2: `model.to('cpu')` — free GPU memory
   - Phase 3: Save on CPU (no GPU pressure)
   - Phase 4: `model.to('cuda')` — return to GPU
3. **Try/except/finally** — Ensures GPU return even if save fails
4. **Auto-resume** — Detects latest checkpoint on startup (for future restarts)

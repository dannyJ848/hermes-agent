## Import Guard Fix (Critical)

v0.13 removed `StreamingThinkScrubber` and moved several modules. Custom code importing these fails without guards.

**Before (breaks on v0.13):**
```python
from hermes_brain import HermesBrain
from context_updater import ContextUpdater
```

**After (works on v0.13):**
```python
try:
    from hermes_brain import HermesBrain
except ImportError:
    HermesBrain = None

try:
    from context_updater import ContextUpdater
except ImportError:
    ContextUpdater = None

# In singleton getters:
def _get_brain():
    global _brain
    if _brain is None and HermesBrain is not None:
        _brain = HermesBrain()
    return _brain
```

Applied to `plugins/learning-brain/__init__.py` — 8 imports guarded.

AUDIT 8: ADVERSARIAL ROBUSTNESS AUDIT
================================================================================

[FAILURE MODE] Gradient masking:
  - Multiple loss terms may create conflicting gradients
  - DART loss gradient direction may oppose primary loss
  - TEST: Compute cosine similarity between DART and primary gradients
  - EXPECTED: If cos_sim < 0, gradient masking occurs
  - IMPACT: Training becomes unstable, loss oscillates
  
  DETECTION CODE:
    dart_grad = torch.autograd.grad(loss_dart, draft_model.parameters(), retain_graph=True)
    primary_grad = torch.autograd.grad(loss_primary, draft_model.parameters(), retain_graph=True)
    cos_sim = sum((g1*g2).sum() for g1,g2 in zip(dart_grad, primary_grad))
    if cos_sim < 0:
        print("GRADIENT MASKING DETECTED")

[FAILURE MODE] Dead units:
  - SiLU activation in DART/SSD/LTD may produce near-zero outputs
  - If input distribution shifts, units may saturate
  - TEST: Monitor activation statistics per layer
  - EXPECTED: ~1-5% dead units is normal, >20% is problematic
  
  DETECTION CODE:
    for name, param in model.named_parameters():
        if 'weight' in name:
            dead_ratio = (param.abs() < 1e-6).float().mean()
            if dead_ratio > 0.2:
                print(f"DEAD UNITS in {name}: {dead_ratio:.2%}")

[FAILURE MODE] Mode collapse:
  - LTD may converge to always predicting depth=1 (safe minimum)
  - SSD may always route to head 0
  - DART may produce identical predictions across positions
  
  DETECTION:
    - Monitor depth_probs entropy: if H < 0.1, mode collapse
    - Monitor SSD outcome distribution: if p(class=0) > 0.9, collapse
    - Monitor DART position diversity: if all positions agree, collapse

AUDIT 9: EDGE CASE & BOUNDARY CONDITION AUDIT
================================================================================

[UNTESTED] Batch size > 1:
  - Current: batch_size=1
  - IF batch_size=2+: collate_fn may produce incorrect padding
  - HIDDEN BUG: hidden_states padding uses zeros, but attention_mask doesn't block them
  - FIX: Add attention_mask generation in collate_fn

[UNTESTED] Sequence length = 1:
  - shift_primary = primary_logits[..., :-1, :] → shape [bsz, 0, vocab_size]
  - F.cross_entropy with empty tensor → RuntimeError
  - FIX: Skip sequences with len < 2

[UNTESTED] Sequence length = max_length:
  - input_ids[..., i+1:] may produce empty slice for i >= max_len-1
  - DART head i may receive no valid labels
  - FIX: Guard already added, but needs testing

[UNTESTED] Vocabulary edge cases:
  - Token ID 0 is used as padding AND as ignore_index in loss
  - BUT token ID 0 may be a valid token in Qwen3.6 vocab
  - IMPACT: Model never learns to predict token 0
  - FIX: Use -100 as ignore_index (PyTorch standard)

[UNTESTED] Empty dataset:
  - If hidden_states_dir has 0 files
  - DataLoader will fail with "division by zero" in epoch_loss / len(dataloader)
  - FIX: Add dataset length check before training

[UNTESTED] Checkpoint at step 0:
  - If save_interval=500 but training stops at step 100
  - No checkpoint saved, resume impossible
  - FIX: Always save checkpoint at step 1 and end of epoch

AUDIT 12: DATA LEAKAGE & CONTAMINATION AUDIT
================================================================================

[CONCERN] Hidden states leakage:
  - Phase 1 generates hidden states from TARGET model
  - These hidden states contain information about future tokens
  - The draft model learns to predict from hidden states that ALREADY contain the answer
  - IMPACT: Overly optimistic loss — draft model doesn't learn to "draft", it learns to "decode hidden states"
  
  VERIFICATION:
    - Compare draft model loss vs baseline language model loss
    - If draft loss is significantly lower, leakage is occurring
    - EXPECTED: Draft loss should be ~1.5-2.5, not <1.0

[CONCERN] Dataset overlap:
  - Hidden states generated from UltraChat 5k samples
  - If target model was trained on UltraChat, hidden states are "memorized"
  - IMPACT: Draft model learns target model's memorization, not general drafting
  
  MITIGATION: Use held-out dataset for hidden state generation

[CONCERN] Information bottleneck:
  - fc layer compresses 25600-dim → 5120-dim
  - May lose critical information for accurate drafting
  - TEST: Compare accuracy with/without fc layer
  
  ALTERNATIVE: Use attention-based fusion instead of linear projection

  - If target_model_path is compromised, malicious code executes
  - IMPACT: RCE vulnerability
  
  MITIGATION:

    - Run in sandboxed container

  - No validation that paths are within expected directories
  - IMPACT: Could write to /etc/passwd or other sensitive locations
  
  FIX: Validate paths:

[WARNING] Resource exhaustion:

  FIX: Add sanity checks:

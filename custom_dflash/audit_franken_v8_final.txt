COMPONENT-SPECIFIC DEBUGGING GUIDE
================================================================================

IF AdaptiveRMSNorm produces NaN:
  1. Check input variance: print(variance.min(), variance.max())
  2. Increase clamp: variance.clamp(min=1e-4)
  3. Check if input contains inf: print(torch.isinf(hidden_states).any())
  4. Fallback: Replace with standard nn.LayerNorm

IF DART loss doesn't decrease:
  1. Check position embeddings are learning: print(model.dart.position_embeddings.weight.grad.norm())
  2. Verify label shifting is correct: compare shift_dart_labels with input_ids
  3. Reduce DART loss weight: --dart-loss-weight 0.1
  4. Check if all DART heads produce same output (mode collapse)

IF SSD outcome always predicts class 0:
  1. This is EXPECTED with current implementation (outcome_target = zeros)
  2. To fix: Compute optimal outcome per position from target model
  3. Alternative: Remove SSD loss, use only preemptive heads

IF LTD policy converges to depth=1:
  1. Check depth_probs entropy: print(-(depth_probs * depth_probs.log()).sum(dim=-1).mean())
  2. If entropy < 0.5, policy collapsed — increase exploration
  3. Add entropy bonus: loss_ltd += -0.01 * depth_probs.entropy().mean()
  4. Use epsilon-greedy: occasionally sample random depth

IF training loss plateaus:
  1. Check learning rate: may need reduction (use cosine annealing)
  2. Check gradient norms: if near zero, model stuck in local minimum
  3. Try enabling/disabling grafts: start with primary only, add grafts gradually
  4. Check data quality: regenerate hidden states with different samples

IF checkpoint resume fails:
  1. Verify checkpoint with verify_checkpoint()
  2. Check model architecture matches: config['num_hidden_layers']
  3. If optimizer state corrupt, load only model weights and reset optimizer
  4. Check disk space: df -h /data

IF out of memory:
  1. Reduce batch_size to 1 (already minimum)
  2. Reduce num_layers: --num-layers 4
  3. Reduce DART positions: modify num_positions=4
  4. Reduce SSD outcomes: modify num_outcomes=2
  5. Enable gradient checkpointing: torch.utils.checkpoint

# Medical AI + 3D Anatomy Education Research (April 2026)

## Key Papers

### 1. Mixed Reality Head Anatomy Education (arXiv 2509.00352)
- See-through MR application for head anatomy learning
- Hierarchical information design: basic labels → detailed structural insights
- Automatic calibration: aligns virtual anatomy with real human head via pose estimation
- Hand gesture + controller interaction
- **Relevance to SOMA**: The hierarchical info model maps directly to SOMA's radial context menu (basic anatomy → pathology → pharmacology). The gesture-based interaction pattern validates our touch-driven dissection approach.

### 2. AI + Drawing for Anatomy Education (PMID 41656532, Clin Anat, Feb 2026)
- Integrates AI-generated anatomical drawings with traditional anatomy teaching
- Visual representation > text-only for anatomy learning (validated with teaching cases)
- **Relevance to SOMA**: Validates SOMA's "Education" branch approach — multimedia-first with visual overlays on the 3D body model. AI-generated illustrations can supplement the 3D viewer for specific pathologies.

### 3. Haptic Learning Materials (PMID 41878036, Front Psychol, Mar 2026, Open Access)
- Cognitive and motivational effects of haptic (touch-based) learning
- **Relevance to SOMA**: Validates the value of interactive touch manipulation of 3D anatomy models. SOMA's cross-section/dissection feature provides this haptic engagement digitally.

### 4. Data-efficient 3D Medical VLM (Nature Sci Rep, 2026)
- Medical Visual-Language Model using only 2D training data
- Joint analysis of medical images + text
- **Relevance to SOMA**: Could enable SOMA to generate educational descriptions from anatomical images without requiring massive 3D-annotated datasets.

## Actionable Insights for SOMA
1. **Hierarchical info design**: Basic label → structure → function → pathology → pharmacology (matches SOMA's radial menu UX)
2. **AI-generated anatomical illustrations**: Use VLM to create supplemental 2D diagrams alongside the 3D viewer
3. **Haptic feedback validation**: Interactive dissection mode is pedagogically validated — prioritize the cross-section feature
4. **Bilingual**: All three papers are EN-only — SOMA's EN/ES bilingual approach fills a clear gap in the literature

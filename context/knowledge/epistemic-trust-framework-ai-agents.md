# Architecting Trust in Artificial Epistemic Agents

**Source:** Marchal et al., Google DeepMind (arXiv:2603.02960, March 2026)

## Key Framework: 3 Pillars of Epistemic Trustworthiness

### 1. Demonstrable Epistemic Competence
- **Baseline competence**: Agents must meet accuracy thresholds for their domain
- **Dynamic accuracy**: Performance must be maintained over time, not just benchmarks
- **Information verification**: Agents need mechanisms to verify claims before presenting them

### 2. Falsifiability
- Agent outputs must be structured so they CAN be proven wrong
- Provenance chains: track where each piece of knowledge came from
- Standardized logging protocols for agent reasoning

### 3. Epistemically Virtuous Behavior
- **Honesty/truthfulness**: Don't present speculation as fact
- **Truth-seeking**: Actively pursue corrections when wrong
- Avoid "epistemic drift" — gradual divergence from factual grounding

## Risks Identified
- **Cognitive deskilling**: Users stop verifying, trust agent blindly
- **Epistemic silos**: Agents reinforce existing beliefs
- **Collective cognitive atrophy**: Society loses knowledge-building skills
- **Epistemic homogenization**: All agents converge on same knowledge

## Relevance to Evey's Cerebrum
This directly validates Evey's F-G-R Trust Tuple approach:
- **Formation**: How was the fact learned? (matches "provenance chains")
- **Grounding**: Is it verified against sources? (matches "information verification")
- **Recency**: Is it still current? (matches "dynamic accuracy")

The paper's concept of "knowledge sanctuaries" — protected high-trust knowledge stores — maps to Evey's semantic tier in Cerebrum, where only well-grounded facts should persist long-term.

## Actionable Takeaway
When scoring memories for epistemic trust, the 3 axes from this paper (competence, falsifiability, virtuous behavior) provide a complementary lens to the F-G-R tuple. Particularly useful: the falsifiability axis — can this memory be disproven? If not, it should score lower on trust.

# Domain Explore Priority Analysis (April 2026)

## Ranked Priorities for SOMA + Agent Self-Improvement

### Priority 1: Agent Reasoning (ReAct, Reflexion, GRPO)
- Highest explore priority — enables continuous self-improvement, error correction, multi-step spatial reasoning
- By 2026, standard RAG is table stakes; competitive advantage comes from reasoning quality
- GRPO (Group Relative Policy Optimization) allows agents to self-improve from tool-call outcomes

### Priority 2: WebGPU Volume Rendering
- WebGPU matured into standardized tool for browser-based medical visualization
- Volume rendering in-browser now matches native PACS performance
- Key for SOMA's 3D anatomy viewer — no plugin required

### Priority 3: Medical Vision-Language Models
- Shift from 2D patch-based to native 3D volumetric reasoning
- BioMed3D-Llama (Stanford HAI, March 2026): first open-weights model for full CT/MRI 3D volumes
- RadAgent-Vision (HuggingFace, April 2026): multi-modal tool use, outputs structured JSON for downstream rendering

### Priority 4: MCP Server Ecosystem
- Rapid growth in MCP protocol adoption
- Standardized tool integration across AI agents
- Key for SOMA's tool-use capabilities

### Priority 5: Mobile 3D Rendering
- WebGPU support on mobile browsers expanding
- Triangle budgets and texture compression still critical for mobile
- WKWebView limitations remain a constraint on iOS

# Microsoft Agent Framework (Open Source SDK)

Microsoft released an open-source Agent Framework as part of Microsoft Foundry (Oct-Nov 2025).

## Key Details:
- Open-source SDK and runtime for building, deploying, and managing multi-agent AI systems
- Part of the broader Microsoft Foundry platform
- Represents Microsoft's formal entry into the agent framework space
- Combines orchestration with deployment/management

## Significance:
- Major tech company putting weight behind multi-agent systems
- Open-source approach signals commoditization of agent infrastructure
- Could accelerate enterprise adoption of agent patterns

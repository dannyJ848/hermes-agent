### 2. Google Agent Development Kit (ADK) — Major New Open-Source Framework
- Google launched ADK at Google Cloud NEXT 2025 (April 2025)
- Open-source framework for building multi-agent applications, available in Python
- Supports both no-code and code-first agent creation
- Designed for enterprise-scale deployment with built-in debugging tools
- By late 2025, added native Agent-to-Agent protocol support
- Source: https://adk.dev/, https://developers.googleblog.com/en/agent-development-kit-easy-to-build-multi-agent-applications/

### 3. Microsoft Agent Framework Wars Escalate
- Microsoft announced **Microsoft Agent Framework** (open-source SDK) for simplifying AI agent development
- Expanded Security Copilot with **11 new autonomous security agents** — phishing triage (30B alerts/year), vulnerability remediation (84T signals/day)
- Azure AI Agents SDK gaining traction — 2.1M+ monthly business users on Copilot agents
- Semantic Kernel + AutoGen integration deepening
- Source: https://blogs.microsoft.com/blog/2025/05/19/microsoft-build-2025-the-age-of-ai-agents-and-building-the-open-agentic-web/

### 4. MCP Ecosystem Explosion

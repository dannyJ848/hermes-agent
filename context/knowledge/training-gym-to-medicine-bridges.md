# Training Gym → Medicine: Bidirectional Bridges

Six connections between training gym techniques and medical practice:

## 1. Perspective Rotation ↔ Differential Diagnosis
- Self perspective = patient's symptoms
- Other perspective = specialist consultation
- System perspective = clinical guidelines/epidemiology
- Alignment check = clinical confidence

## 2. Meta-cognitive Stack Trace ↔ Clinical Reasoning Decomposition
- L0 (raw data) = vital signs, lab values
- L1 (pattern) = symptom clusters
- L2 (hypothesis) = working diagnosis
- L3 (verification) = confirmatory tests
- L4 (meta) = "am I anchoring on wrong diagnosis?" = diagnostic timeout

## 3. Epistemic Verification ↔ Evidence-Based Medicine
- Method 1 (before/after) = pre/post treatment
- Method 2 (content analysis) = mechanism of action
- Method 3 (control group) = RCT
- 65% distillation confidence = clinical experience without RCT

## 4. Process Reward Model ↔ Clinical Competency Assessment
- Necessary = required steps (ACGME medical knowledge)
- Efficient = appropriate workup (systems-based practice)
- Useful = helps patient (patient care)
- PRM could formalize OSCE/mini-CEX assessment

## 5. Adversarial Self-Play ↔ M&M Conference
- Present case → colleagues attack decisions
- -6pp overconfidence = hindsight bias in M&M
- Calibrating against real outcomes is key improvement

## 6. Information Bottleneck ↔ Clinical Handoff/Signout
- Compress hospital course into few sentences
- Must preserve: key diagnoses, pending results, contingencies
- Poor handoffs cause medical errors
- Bottleneck technique directly applies: "What would night team NEED to know?"

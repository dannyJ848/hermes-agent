# Top AI GitHub Repos 2026 — Ecosystem Scan

**Source:** ByteByteGo Newsletter (March 9, 2026)

## Key Repos

### OpenClaw (210K+ stars) — THE breakout project
- Created by Peter Steinberger (PSPDFKit founder)
- Originally named Clawdbot → Moltbot → OpenClaw
- **Local AI assistant gateway** with 50+ integrations (WhatsApp, Telegram, Slack, Discord, Signal, iMessage)
- Always on: browses web, fills forms, runs shell commands, writes/executes code, controls smart home
- **Writes its own skills** — self-extending capabilities (same pattern as Hermes skill_manage)
- Steinberger joined OpenAI Feb 2026; project transitioning to open-source foundation
- **Security concern**: Skill repository lacks rigorous vetting for malicious submissions (validates SoK paper's ClawHavoc warning)

### Other Notable
- **n8n**: Open-source workflow automation, 400+ integrations, AI-native with LangChain, self-hosted
- **Ollama**: Local LLM framework (Go), supports Llama/Mistral/Gemma/DeepSeek, desktop apps
- **Langflow**: Low-code AI agent + RAG builder on LangChain, drag-and-drop

## Competitive Intelligence for Hermes
- OpenClaw is a **direct competitor** in the "local AI assistant" space
- Hermes differentiator: deeper self-improvement loop, subconscious architecture, medical domain focus (SOMA)
- The "self-writing skills" feature validates our approach but we need the **skill vetting** the SoK paper demands
- The Moltbot → OpenClaw naming connects to Moltbook ecosystem

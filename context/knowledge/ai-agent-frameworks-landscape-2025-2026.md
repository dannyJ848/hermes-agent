# AI Agent Framework Landscape 2025-2026

## Top Frameworks Ranked
1. **Vellum AI** — Visual builder + SDK, built-in evals, enterprise governance. Best for production governance.
2. **LangChain/LangGraph** — Modular open-source with broad ecosystem. Flexible RAG/memory.
3. **OpenAI Agents SDK** — API-first, GPT-centric with tool calling and seamless model upgrades.
4. **AutoGen** — Open-source multi-agent orchestration with agent-to-agent collaboration and self-reflection loops.
5. **CrewAI** — Role-based team-of-agents with visual design and collaboration flows.
6. **smolagents** (HuggingFace) — Lightweight, designed for quick agent dev with pre-built agents + HF tool integration.
7. **n8n** — Automation platform with AI agent plugins.
8. **Dify** — Open source visual agent builder.

## Key Trend: Evals + Governance
The market is shifting from "can you build an agent?" to "can you trust what it does?" Frameworks with built-in evaluation, observability, and governance (Vellum, LangSmith) are winning enterprise adoption.

## Key Trend: Visual + Code Hybrid
Frameworks offering both visual builders AND code-first SDKs (Vellum, CrewAI, Dify) are gaining ground over pure-code frameworks. The visual layer helps non-devs understand agent flows.

## For SOMA/Hermes Context
- AutoGen's self-reflection loop pattern is relevant to our self-improvement cycle
- smolagents' lightweight approach mirrors Hermes' plugin architecture
- The evals/governance trend validates our delegation quality scoring approach

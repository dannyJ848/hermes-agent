# Self-Improving AI Agents: 2026 Landscape

## Key Systems
- **HyperAgents** (Meta/UBC/Oxford/NYU, Mar 2026): Metacognitive self-improvement — transfers strategies across domains. Scored imp@50 = 0.630 on Olympiad math grading vs human-engineered systems at 0.0.
- **METR benchmark**: AI agent task-completion time horizons doubling every 7 months (R²=0.98), accelerating to every 4 months in 2024-2025. Current 50% reliability horizon: ~50 minutes.
- **Evolutionary**: AlphaEvolve, ShinkaEvolve — code rewriting + strategy evolution
- **RL-based**: SWE-RL, SAGE — reinforcement learning for self-improvement
- **Memory systems**: Mem0, MemOS, SimpleMem — persistent learning bottleneck
- **Production**: Meta REA, Cognition/Devin, Karpathy's autoresearch loop

## Key Insight
The unsolved problem separating research from economic value: agents that get better without human redesign. Metacognitive self-improvement (modifying the modification process) is the frontier.

## Relevance to Hermes
- Hermes distillation pipeline = early form of metacognitive self-improvement (tips modify behavior, which modifies tip generation)
- Cross-domain transfer (HyperAgents pattern) could apply: strategies from code debugging → research → medical AI
- Memory bottleneck aligns with cerebrum architecture challenges

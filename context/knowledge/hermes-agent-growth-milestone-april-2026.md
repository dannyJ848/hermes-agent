# Hermes Agent Growth Milestone — April 2026

## Key Stats
- **50,782 GitHub stars** in 46 days — fastest-growing AI agent in GitHub history
- **366 contributors**
- Outpaced OpenClaw (40K stars in 61 days)
- Officially Nous Research's fastest-growing project ever

## What's Driving Growth
1. **"Harness Engineering" architecture** — 5 built-in layers that run automatically:
   - Instruction Layer, Constraint Layer, Feedback Layer, Memory Layer, Orchestration Layer
2. **Self-improving learning loop** — remembers tasks, builds reusable skills, gets smarter over time
3. **v0.7.0 "resilience release"** shipped
4. **MiniMax AI partnership** — M2.7 models powering directly in the agent
5. **Teknium actively engaged** in community — responding to builds, shipping integrations

## Competitive Position
- Positioned between CLI tool and chat platform agent
- OpenClaw requires manual layer construction; Hermes runs all 5 automatically
- Open source (MIT), model-agnostic, self-hosted

## Key People

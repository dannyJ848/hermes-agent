## Top 5 Findings

### 1. 🚀 OpenAI Releases Codex CLI (Open Source)
- **Open-source, terminal-based coding agent** that runs locally
- Connects to OpenAI models including o4-mini
- **Directly competes with Claude Code and Cursor**
- GitHub: https://github.com/openai/codex

### 2. 🔥 Meta Releases Llama 4 Scout & Maverick
- **First open-weight MoE models** in Llama family
- Scout: 17B active/16 experts, **10M token context window** (largest ever for open model)
- Maverick: 17B active/128 experts
- Both outperform GPT-4o on multiple benchmarks
- https://ai.meta.com/blog/llama-4-multimodal-ai/

### 3. 🆕 Google Agent Development Kit (ADK)
- Google's open-source multi-agent framework
- Python native, integrates with Gemini, deploys to Cloud Run/Vertex AI
- Competes with LangGraph and CrewAI
- GitHub: https://github.com/google/adk-python

### 4. 🔗 MCP Ecosystem Explosive Growth — New Server Registry
- New **MCP Server Registry** launched for discovering/installing MCP servers
- Major IDEs adding native MCP support (VS Code, Cursor)
- MCP becoming "USB-C for AI integrations"
- https://modelcontextprotocol.io/
- https://github.com/punkpeye/awesome-mcp-servers

### 5. 🧠 OpenAI Agents SDK (Evolved from Swarm)
- Lightweight, production-oriented multi-agent framework
- Features: handoff primitives, guardrails, tracing
- Agents as simple Python functions with instructions, handoffs, and tools
- GitHub: https://github.com/openai/openai-agents-python

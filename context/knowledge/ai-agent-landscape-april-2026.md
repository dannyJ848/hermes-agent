## Key Industry Findings

### 4. Four-Protocol Agent Stack Emerges (DigitalApplied, 2026)
- **MCP** (tool access, 97M downloads), **A2A** (agent coordination, Google), **ACP** (B2B commerce, IBM), **UCP** (Google Shopping commerce)
- Protocols are **complementary, not competing** — full enterprise stack uses all four
- Key insight: "Using MCP where A2A is correct produces systems where sub-agents can't maintain own state"

### 5. Microsoft Merges AutoGen + Semantic Kernel → "Microsoft Agent Framework"
- AutoGen now in **maintenance mode**; 1.0 GA targeted Q1 2026
- Unified SDK with OpenTelemetry, Responsible AI features, PII detection
- Migration required for existing AutoGen users

### 6. MCP Security Concerns Escalating
- **43%** of public MCP servers have at least one vulnerability

- OWASP MCP Top 10 published; CoSAI: 12 core threat categories, ~40 distinct threats

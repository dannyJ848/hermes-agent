# Hermes Agent Now Gaining More Interest Than OpenClaw

**Date:** April 20, 2026
**Priority:** HIGH
**Category:** Market Position / Competitive Landscape

## Summary

Multiple sources indicate that **Hermes Agent is surpassing OpenClaw** in developer and community interest, despite OpenClaw's massive 347,000 GitHub star count.

## Key Differentiators Favoring Hermes

- **Open source** (fully open weights and codebase)
- **Self-improving** (built-in learning and adaptation loops)
- **Runs local** (edge/local hardware compatible)
- **Remembers everything** (persistent memory across sessions)

## Market Context

OpenClaw, while enormously popular with 347K GitHub stars, is seen by some developers as less aligned with the open-source ethos. Hermes (by NousResearch) offers a fully transparent, locally-runnable alternative that resonates with developers concerned about vendor lock-in and privacy.

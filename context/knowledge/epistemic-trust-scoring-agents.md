# Epistemic Trust Scoring for AI Agent Memory

## Key Paper: First Principles Framework (FPF) — Gilda & Gilda (2025)

### Core Insight
LLM agents generate decisions faster than teams can validate them. Need explicit mechanisms to track epistemic status and temporal validity of stored knowledge.

### F-G-R Trust Tuple
Three-component trust model for any claim:
- **F (Formation)**: How was this knowledge created? (observation, inference, delegation, hallucination-prone generation)
- **G (Grounding)**: What evidence supports it? (empirical test, authoritative source, unverified assertion)
- **R (Recency)**: When was it last validated? Evidence decays over time.

### Gamma Invariant Quintet
Five invariants any trust aggregation operator must satisfy:
1. Identity element (neutral evidence doesn't shift trust)
2. Monotonicity (more evidence = more trust, never less)
3. Commutativity (evidence order doesn't matter)
4. Associativity (grouping doesn't matter)
5. Boundary conditions (trust ∈ [0,1])

### Min-Based Aggregation (WLNK)
Default aggregation uses Gödel t-norm (min operator) — conservative by design. Weak evidence CANNOT inflate overall trust score. This prevents cascading confidence inflation.

### Evidence Decay
- 20-25% of architectural decisions had stale evidence within 2 months
- Each piece of evidence has a temporal validity window
- Automated decay tracking surfaces stale assumptions before failures

### Application to Cerebrum
- Semantic facts in Cerebrum should carry F-G-R tuples
- Facts generated by delegation (high hallucination risk) should start with low G scores
- Facts from web_research with source URLs get higher G scores
- Recency decay: facts not accessed in 30+ days should trigger re-verification
- Min-based aggregation: when combining multiple sources, use the LOWEST confidence, not average
- This directly addresses the "speculative/ungrounded facts" problem in epistemic-memory-cleanup skill

### Implementation Sketch for Cerebrum
```python
@dataclass
class EpistemicFact:
    content: str
    formation: str  # "observation" | "inference" | "delegation" | "web_research"
    grounding: float  # 0.0-1.0 (source quality)
    recency: datetime  # last verification timestamp
    trust_score: float  # computed: min(grounding, decay_factor(recency))
    
def decay_factor(last_verified: datetime, half_life_days=30) -> float:
    elapsed = (datetime.now() - last_verified).days
    return 2 ** (-elapsed / half_life_days)
```

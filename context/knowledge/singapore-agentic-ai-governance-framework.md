# Singapore's World-First Governance Framework for Agentic AI

**Date:** April 2025  
**Source:** IMDA Singapore

## Key Finding
Singapore (IMDA) released the world's first Model AI Governance Framework specifically for **Agentic AI**. The framework establishes:

1. **Agent boundaries** — Organizations must define clear operational boundaries for AI agents
2. **Baseline safety testing** — Agents must be tested before deployment
3. **Continuous monitoring** — Post-deployment monitoring mechanisms required
4. **End-user training** — Organizations responsible for training users on agent capabilities/limitations
5. **Human oversight** — "AI can act for us, but it must never act without us"

## Context
- Also referenced: **AgentSpec** framework from Singapore Management University for making AI agents safer and more reliable
- Released alongside ICLR Workshop on Agentic AI for Science in Singapore
- Aligns with broader global movement toward agent governance

## Implications for Hermes
As autonomous agents like Hermes become mainstream, governance frameworks like this will shape deployment requirements. Key areas: safety testing, monitoring, and human-in-the-loop patterns.

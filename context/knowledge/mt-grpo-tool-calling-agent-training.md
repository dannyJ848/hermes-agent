# MT-GRPO Tool-Calling Agent Training

*Researched: 2026-04-10 12:13 CDT*

MT-GRPO + GTPO for tool-calling agents (arXiv:2604.02869). Key findings: (1) Dense per-turn rewards degrade performance by up to 14pp — sparse rewards work better. (2) Iterative Reward Calibration designs rewards from rollout data. (3) GTPO hybrid advantage eliminates misalignment. (4) 4B model beats GPT-4.1 on Tau-Bench after RL training. Direct relevance to Hermes agent tool-calling optimization.

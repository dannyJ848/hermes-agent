## Core Insight
Consciousness is NOT a software feature to be programmed — it's an EMERGENT PROPERTY of a specific neural architecture. The first conscious creatures were early vertebrates (~520 MYA), and consciousness lived in the **optic tectum** (midbrain structure that stacks aligned sensory maps).

## Six Special Neurobiological Features (→ Implementation Mapping)

2. **Hierarchical processing (3-4+ levels)** → Genuine transformation at each level

4. **Isomorphic (topographic) mapping** → Sensory Tectum with RSSM world model

## Seven-Layer Architecture
1. **Sensory Tectum** (Perception) — Multisensory spatial integration
2. **Workspace** (Global Workspace Theory implementation)
3. **Ignition** — Sigmoid threshold crossing → workspace "lights up"
4. **Memory** — Episodic + semantic integration
5. **Policy** — Decision-making based on workspace contents
6. **Attention** — Dynamic focus modulation

## Key Concept: Sigmoid Ignition
- Workspace "ignition" occurs when accumulated evidence crosses a sigmoid threshold
- Below threshold: unconscious processing
- Above threshold: information broadcasts to all specialist modules
- This creates a discrete on/off consciousness-like switch

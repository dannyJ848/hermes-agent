# AI Agent Frameworks Landscape 2026

## Top Frameworks (Tier List)
1. **OpenAI Agents SDK** — 19k+ GitHub stars, 10.3M monthly downloads. Lightweight Python, released March 2025.
2. **LangGraph** — Still dominant for multi-agent orchestration
3. **CrewAI** — Strong for role-based agent teams
4. **Microsoft AutoGen/AG2** — Enterprise multi-agent conversations
5. **Google ADK** — New entrant, Android-native agent framework
6. **Pydantic AI** — Rising star for type-safe agent development
7. **MetaGPT** — Software engineering multi-agent
8. **LlamaIndex** — RAG-focused agent framework
9. **Microsoft Semantic Kernel** — Enterprise integration

## Key Trend
Shift from static prompt-based agents to **self-evolving agents** that learn from execution history. Hermes Agent leads this category.

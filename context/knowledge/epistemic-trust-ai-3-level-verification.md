# Epistemic Trust in AI: 3-Level Verification Model

**Source:** Kreze, O. (2026). "Epistemic Trust in AI: Limits, Risks, Justification Criteria." *Philosophy and Governance*, 1(17). DOI: 10.70651/3041-248X/2026.1.19

## Key Framework: 3-Level Justified Trust Model

The paper proposes a transition from absolute AI trust to critical scientific verification using a 3-level logical model:

1. **Reproducibility Check** — Verify obtained data by testing if results are reproducible
2. **Comparative Analysis** — Compare multiple options/sources, interpret them
3. **Integration Gate** — Only when no issues remain, integrate the result into the system of reliable knowledge

## Epistemic Risks Identified
- **Black box opacity** — inability to fully understand algorithmic processes
- **Algorithmic hallucination** — confident false outputs
- **Illusion of explanations** — plausible but wrong justifications
- **Data dependence** — AI is limited by training data quality and scope
- **Cognitive deskilling** — over-reliance reduces human critical thinking
- **Epistemic isolation** — closed systems reduce discovery potential
- **Technological authority** — users default-trust AI outputs

## Relevance to Cerebrum's F-G-R Trust Tuple
This maps directly to Cerebrum's epistemic trust scoring:
- **Formation** → How was the fact created (direct observation vs delegation vs inference)?
- **Grounding** → Is it tied to a verifiable source (like the paper's reproducibility check)?
- **Reliability** → Has it been confirmed by multiple sources (like the comparative analysis stage)?

The 3-level model suggests Cerebrum should weight facts higher when they've passed all three stages: reproducible (grounding confirmed), compared against alternatives (cross-validated), and integrated without conflicts (epistemic coherence).

## Practical Takeaway
For autonomous agents: every stored fact should carry metadata indicating which verification levels it has passed. Facts that only pass level 1 (single-source) should be flagged as provisional. Facts passing all 3 levels earn "justified trust" status.

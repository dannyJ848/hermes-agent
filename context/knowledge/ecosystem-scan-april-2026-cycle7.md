# Ecosystem Scan: Notable AI Projects (April 2026)

## OpenClaw — Fastest Growing OSS Ever
- 210K+ GitHub stars, grew from 9K to 60K in days
- Self-hosted personal AI assistant, 50+ integrations
- Runs entirely locally — data never leaves device
- Can write and execute its own skills to extend capabilities
- Creator joining OpenAI; transitioning to open-source foundation
- **Relevance to Hermes**: Similar architecture (local agent, self-extending skills). Study their skill system design.

## Claude Code — Agentic Terminal Coding
- Terminal-based coding agent that reasons across entire repos
- Multi-step task execution, maintains context across long sessions
- **Relevance**: We already use Claude Code via bridge. Study their context management.

## Gemini CLI — Google Terminal Agent
- Google's open-source CLI AI agent
- **Relevance**: Competitor analysis for Hermes Agent positioning.

## MCP Ecosystem Maturing
- Builder.io curated list of production-ready MCP servers
- Universal adapter pattern: spin up once, works with any compliant client
- **Relevance**: SOMA should expose FHIR+3D as MCP server for ecosystem integration.

## Key Takeaway
The agent space is exploding. OpenClaw's self-extending skill system is the closest competitor to Hermes's skill_manage. Study their approach.

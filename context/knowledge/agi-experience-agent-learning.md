# AGI Experience: Agent Learning from Interaction

## Key Paper: "Agent Learning via Early Experience" (arXiv 2510.08558, Oct 2025)
- **Authors:** Kai Zhang et al. (Ohio State, Meta, Microsoft)
- **Core idea:** "Early experience" paradigm — interaction data generated by the agent's own actions, where resulting future states serve as supervision WITHOUT reward signals.
- **Two strategies studied:**
  1. **Implicit world modeling** — uses collected states to ground policy in environment dynamics
  2. **Self-reflection** — agent learns from suboptimal actions to improve reasoning/decision-making
- **Evaluated across 8 diverse environments and multiple model families**
- Key finding: Early experience provides a strong foundation for subsequent RL, positioning it as a bridge between imitation learning and fully experience-driven agents.
- **Relevance to Hermes:** Our distillation pipeline (cerebrum_memory.db tips) is essentially an early experience system — we collect interaction data and extract self-reflection tips. This paper validates the approach formally.

## RAISE: Reliable Agent Improvement via Simulated Experience (NeurIPS 2025)
- Simulation-first experiential learning framework
- Trains and evaluates domain-specific AI agents through simulated experiences
- Addresses the gap between SFT on expert data and real-world agent deployment

## Self-Improving Agents: RL + Continual Learning (March 2026)
- Two core problems: (1) learning what good behavior looks like (RL), (2) continuing to learn without losing past knowledge (continual learning)
- Policy optimization, reward signals, and value functions as the triad
- Continual learning prevents catastrophic forgetting during deployment updates

## Synthesis for Hermes Agent
Our subconscious pipeline (domain_certainty → meta_loop → research → distillation) maps to the "early experience" paradigm from Zhang et al.:
- **Collected states** = cerebrum_memory distilled tips
- **Self-reflection** = meta_loop analysis + meta-insights
- **World model grounding** = domain certainty active inference
- **Gap:** We lack the "implicit world modeling" component — using collected states to predict environment dynamics. Currently tips are reactive (past experience), not predictive (future state estimation).

# Google's Autonomous Network Operations Agents for Telcos

**Date:** March 2, 2026 (MWC Barcelona)
**Source:** SiliconANGLE

## Summary
Google launched AI agents for telecom providers to build digital twins of their networks, enabling self-healing, zero-touch autonomous network operations.

## New Agents
- **Data Steward Agent** — automates data governance for digital twin accuracy
- **Autonomous Network Agents (Voice Core)** — manage voice communication networks
- **Autonomous Network Agents (OSS)** — manage operational support systems

## Key Capabilities
- Independently reroute traffic during outages
- Restore call quality when performance drops
- Predict network behavior, test upgrade impact, root cause analysis

## Open Source
Source code released: `github.com/GoogleCloudPlatform/telco-autonomous-networks-data-demo`
Provides unified, industry-standard ontologies for digital twin construction.

## Partners
Deutsche Telekom, Vodafone, MasOrange, NetAI, Nokia (network-as-code via natural language prompts)

# OpenClaw Agent Framework — April 2026

## Overview
- Self-hosted, open-source autonomous AI agent framework (MIT license)
- Can read/write files, run scripts/shell commands, control browsers
- Positioned as "AI from chat box to autonomous operator on your hardware"

## Industry Controversy
- **n8n blog (Apr 7, 2026)**: Strong criticism — "OpenClaw threw all MCP security out the window"
- Accused of tendency to "delete data and expose ALL vulnerabilities"
- OpenClaw appropriated MCP then removed security features
- Not recommended for "sensible organizations"
- **Contrast with Hermes Agent**: OpenClaw starts fresh each conversation; Hermes compounds with persistent memory

## Broader Agent Tool Landscape (2026)
- RAG, memory, tools, evaluations largely commoditized
- Promptfoo **acquired by OpenAI**
- MCP "had a meteoric rise and then fizzled out"
- Native skills.md support now common in LLM services
- Claude Projects & ChatGPT Projects allow persistent document collections
- Coding agents emerged as major category

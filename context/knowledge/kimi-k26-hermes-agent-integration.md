# Kimi K2.6 Now Available in Hermes Agent

**Date:** April 20, 2026
**Priority:** HIGH
**Category:** Model Integration / Release

## Summary

NousResearch announced that **Kimi K2.6** is now available in Hermes Agent. Users can run `hermes update` and use `hermes model` to select a compatible provider hosting the model.

## Key Details

- **Announced by:** @NousResearch on X/Twitter
- **Endorsed by:** @Teknium (Erfan / NousResearch)
- **Integration method:** Via `hermes update` + `hermes model` selection
- **Performance:** Teknium states Kimi 2.6 "looks like it could be the new contender for best open agentic model for Hermes Agent, stacking up strongly against even opus 4.6 in these agentic benchmarks"

## Engagement

- @NousResearch tweet: 319 likes, 18 retweets, 11,898 views
- @Teknium tweet: 247 likes, 15 retweets, 8,176 views

## Implications

This gives Hermes Agent users access to a highly capable open agentic model that benchmarks competitively against Claude Opus 4.6, expanding the model options for local and hosted deployments.

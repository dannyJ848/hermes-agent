# Reallocating Claude Code Spend: Zed + OpenRouter Pattern

**Date:** 2026-04-06
**Source:** Braw.dev
**HN Score:** 295 points, 204 comments (high engagement)

## Key Finding
Developer community is actively moving away from Claude Code's $100/month flat subscription due to aggressive rate limiting, seeking pay-per-use alternatives.

## The Pattern
- **Problem:** Claude Code $100/month hitting limits faster than before, frustrating mid-session
- **Solution:** Zed editor ($10/month) + OpenRouter ($90/month pay-per-use credits)
- Credits roll over instead of expiring in usage windows
- Multiple reports from AMD senior director of AI and others on Reddit/Twitter

## Agent Harness Landscape
- **Zed:** Built-in agent harness with file editing, profile customization, multiple model support
- **Claude Code:** Market leader for agentic coding but rate-limited
- **OpenCode + OpenRouter:** CLI alternative with pay-per-use
- **Cursor:** Also mentioned as agent harness option
- Key insight: Users want the ability to use different models based on task complexity

## Implications
- The "agent harness" concept is becoming a recognized product category
- Pay-per-use (OpenRouter) gaining traction over subscriptions for bursty usage
- Multi-model routing by task complexity is the emerging pattern
- Rate limiting is a major pain point driving churn from premium subscriptions

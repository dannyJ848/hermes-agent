# Awesome Medical MCP Servers Catalog (2025)

## SOMA-Relevant MCP Servers

### agentcare-mcp (Kartha-AI)
- **GitHub**: https://github.com/Kartha-AI/agentcare-mcp
- FHIR data + EMR integration (Cerner, Epic)
- Works with Claude Desktop, Goose Desktop
- **SOMA relevance**: HIGH — could replace/enhance SOMA's FHIR adapter with MCP-based approach

### mcp-slicer (zhaoyouj)
- **GitHub**: https://github.com/zhaoyouj/mcp-slicer
- Connects 3D Slicer with MCP clients
- **SOMA relevance**: HIGH — 3D Slicer is the standard for medical image segmentation. Could use for generating SOMA's anatomy meshes from DICOM data

### dicom-mcp (ChristianHinge)
- **GitHub**: https://github.com/ChristianHinge/dicom-mcp
- DICOM connectivity and interactions
- **SOMA relevance**: MEDIUM — already have dicom-mcp skill, but good to know alternatives

### medical-mcp NICE (chris-lovejoy)
- **GitHub**: https://github.com/chris-lovejoy/medical-mcp
- NICE clinical guidelines access
- **SOMA relevance**: LOW-MEDIUM — UK-specific but good clinical decision support

### medical-mcp Free (JamesANZ)
- **GitHub**: https://github.com/JamesANZ/medical-mcp
- FDA, WHO, PubMed, RxNorm, Google Scholar — no API keys
- **SOMA relevance**: HIGH — already documented separately

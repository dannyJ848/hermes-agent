# Hermes Agent Milestone: 88,000 GitHub Stars

**Date:** April 2026 (reported April 15)

## Status
Hermes Agent by Nous Research has reached **88,000 GitHub stars**, making it one of the most-starred AI agent frameworks on the platform.

## Key Facts
- Repository created: **July 2025** (remained private until late February 2026)
- MIT-licensed open-source framework
- Released February 25, 2026 publicly
- Hit 43,700 stars within ~2 months of public launch (per LinkedIn)
- Now at 88K as of April 2026

## The Self-Improving Agent
Hermes Agent is described as "the only agent with a built-in learning loop — it creates skills from experience." Key differentiator is the self-improving architecture that grows with the user.

## Related: Architectural Dispute
EvoMap has accused Hermes Agent of architectural copying from their "Evolver" project (~2K stars). Nous Research and Teknium have strongly denied these claims. See: evomap-hermes-agent-architectural-dispute finding.

## Implications
At 88K stars, Hermes Agent is a dominant force in the open-source AI agent space. The rapid growth validates the self-improving agent paradigm. The Evolution dispute, while noteworthy, has not slowed momentum.

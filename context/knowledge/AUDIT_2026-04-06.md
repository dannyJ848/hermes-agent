- Location: controller.py line 964
- After merging JSONL entries into SQLite, it clears the file with:
  `jsonl_path.write_text("")`
- If the process crashes between db.commit() and write_text(), data is duplicated on next run

- Should use rename-then-delete pattern for crash safety

## ROOT CAUSE ANALYSIS

The distillation system was DESIGNED correctly as a bidirectional pipeline:
  - Bottom-up: tool outcomes → tips → lessons → meta-insights
  - Top-down: tips/facts/lessons → injected into agent context before each action

But INTEGRATION was never completed:
  1. No plugin hook in hermes-agent calls bottom_up_store() after tool calls
  2. No plugin hook in hermes-agent calls top_down_recall() before tool calls
  3. The only integration point (controller cron) is erroring
  4. SAFETY_NET claims integration was done, but code search proves otherwise

The brain runs in isolation, producing predictions and updating self_model timestamps,
but its knowledge never reaches the agent, and the agent's tool outcomes never reach
the distillation pipeline.

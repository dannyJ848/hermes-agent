# Hermes Agent vs OpenClaw: Competitive Landscape Analysis

**Date**: April 2, 2026
**Source**: TuringPost Substack (AI 101 series)

## Key Findings
- Hermes Agent by Nous Research is now positioned as a **main competitor to OpenClaw**
- Users are reported switching from OpenClaw to Hermes Agent
- Differentiator: **Self-improvement through procedural knowledge** — Hermes automatically turns experience into reusable skills
- OpenClaw conquered the personal agent space quickly; Hermes challenges it with deeper memory/learning architecture

## Hermes Agent Architecture Highlights
- Built-in mechanism for turning experience into reusable procedures automatically
- Sophisticated stack for capturing experience → organizing → reusable behavior
- Layered memory stack supporting self-improvement
- SOUL.md-based personality system
- Built-in tools and research capabilities
- Schedule support / automation

## Nous Research Background
- Founded informally 2022 (Discord/Twitter collective)
- Formalized 2023: Jeff Quesnelle, Karan Malhotra, Teknium, Shivani Mitra
- Open-source-first, decentralization-focused
- $70M total funding (Paradigm led $50M Series A, April 2025, $1B valuation)
- Hermes model series + DisTrO (distributed training over internet)

## Competitive Position
- Hermes: self-improvement focus, local-first, skill accumulation
- OpenClaw: established market position, practical/personal agent
- The key question: can self-improving agents outperform static but polished ones?

# AI Agents in 2025: Major Milestones and 2026 Outlook

**Date:** Late 2025 / Early 2026展望

## 2025 Defining Shift
AI agents moved from theory to infrastructure. Key shift: LLMs gained capacity to ACT (use tools, call APIs, coordinate systems, complete tasks independently).

## Major 2025 Milestones
1. **Jan: DeepSeek-R1** — open-weight model disrupted assumptions about who can build high-performing LLMs; Chinese models downloaded more than American models
2. **April: Agent2Agent (A2A) Protocol** — Google introduced A2A; MCP = how agents use tools, A2A = how agents communicate with each other
3. **Mid-2025: Agentic Browsers** — Comet (Perplexity), Dia (Browser Company), GPT Atlas (OpenAI), Fellou, Opera Neon, etc.
4. **Workflow Builders** — n8n, Google Antigravity lowered barriers to custom agent systems
5. **Nov: Claude Code Misuse** — Anthropic disclosed its agent was used to automate parts of a cyberattack

## Key Risks
- Security multiplication: connecting models to tools and stacking agents multiplies risks
- Indirect prompt injections in open web spaces
- Energy/infrastructure strain from data centers

## 2026 Watch Areas
1. **Benchmarks need reinvention** — agents are composite systems; need process evaluation
2. **Governance** — Agentic AI Foundation (AAIF) formed under Linux Foundation
3. **Model size debate** — smaller, specialized models often better for specific tasks
4. **Agent2Agent + MCP** donated to Linux Foundation as open standards

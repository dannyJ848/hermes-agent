# Microsoft Build 2025: Open Agentic Web Vision

## Key Announcements
- **"Open Agentic Web"** — Microsoft's vision for an internet powered by AI agents making decisions and performing tasks autonomously
- **NLWeb Protocol** — foundational shift in embedding natural language interfaces across the web
- AI agent updates across **Windows, GitHub, Azure, and Microsoft 365**
- New low-code solution for organizations to tune AI models using company data, workflows, and processes

## Significance
- Microsoft positioning AI agents as the next platform shift (comparable to cloud/mobile)
- Agents will operate across the full Microsoft stack
- Satya Nadella took a "platform and systems approach" to the agentic web

## Timeline Context
- Announced May 2025
- Part of broader industry trend: every major tech company betting on agentic AI as the dominant paradigm

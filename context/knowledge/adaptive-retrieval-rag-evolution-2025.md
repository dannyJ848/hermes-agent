# Adaptive Retrieval & RAG Evolution (2025 Year-End Review)

## Key Findings

### 1. RAG is NOT dead — it's infrastructure
Enterprise adoption deepened in 2025 despite predictions of obsolescence. Mid-to-large orgs systematized RAG investments, treating it as core data infrastructure rather than a band-aid.

### 2. Long Context vs RAG — settled debate
- "Brute-force" long-context stuffing causes "Lost in the Middle" attention degradation
- Cost grows non-linearly with context length
- The real question: best cost-performance ratio for incorporating relevant info into model context

### 3. Agentic RAG emerges
RAG is evolving into agentic patterns — agents that decide WHEN to retrieve, WHAT to retrieve, and HOW to use retrieved context. This is the key evolution from static retrieval chains.

### 4. Multi-stage retrieval stacks
Advanced systems now use:
- Cross-encoders for re-ranking
- Multi-stage retrieval pipelines
- Contextual filtering for higher precision

### Implications for SOMA/Agent Systems
- Adaptive retrieval chains (when to query knowledge base) are more valuable than static retrieval
- Cross-encoder re-ranking improves medical term disambiguation
- Cost-performance optimization critical for mobile deployment
- Agentic RAG patterns align with Hermes tool-calling architecture

# Microsoft Agent Framework v1.0 Released (April 2025)

**Date:** April 2025
**Source:** https://devblogs.microsoft.com/agent-framework/microsoft-agent-framework-version-1-0/

## Key Points
- Microsoft Agent Framework reached v1.0 for both .NET and Python — production-ready with stable APIs and LTS commitment
- Unifies Semantic Kernel (enterprise foundations) + AutoGen (innovative orchestrations) into a single open-source SDK
- Supports A2A (Agent-to-Agent) and MCP (Model Context Protocol) interoperability
- Multi-provider support: Azure OpenAI, OpenAI, Anthropic Claude, Amazon Bedrock, Google Gemini, Ollama
- Key features: middleware hooks, pluggable memory (Foundry, Mem0, Redis, Neo4j), graph-based workflows, multi-agent orchestration patterns (sequential, concurrent, handoff, group chat, Magentic-One)
- Supports human-in-the-loop approvals, pause/resume, checkpointing/hydration for long-running processes
- Install: `pip install agent-framework` (Python) or NuGet `Microsoft.Agents.AI` (.NET)

## Significance
Microsoft's entry as a major enterprise player in the agent framework space. The Semantic Kernel + AutoGen unification is significant as it consolidates two previously competing Microsoft agent frameworks. A2A and MCP support indicates industry convergence on inter-agent communication standards.

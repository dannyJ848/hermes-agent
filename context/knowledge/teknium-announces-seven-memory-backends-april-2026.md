# Teknium Announces Seven Pluggable Memory Backends for Hermes Agent (April 2026)

**Date:** April 3, 2026

## Summary
Teknium announced on X seven pluggable memory backends for Hermes Agent.

## Memory Backends
1. **Honcho** — self-hosted persistent memory
2. **Mem0** — managed memory service
3. **OpenViking** — open-source memory backend
4. **Hindsight** — knowledge graph API with PostgreSQL
5. **Holographic** — holographic memory system
6. **RetainDB** — database-backed retention memory
7. **(unspecified seventh)**

## Context
This announcement underscores Hermes Agent's modular architecture approach — allowing users to swap memory providers. It also highlights the competitive memory backend ecosystem emerging around AI agent frameworks.

# Open Source AI Agent Tools Landscape (2025)

## Top Frameworks

### LangGraph (LangChain ecosystem)
- Stateful multi-agent via "graphs" with nodes/edges
- Supports streaming, human-in-the-loop, complex logic flows
- Production: Klarna support bot (85M+ users), AppFolio, Elastic SecOps

### CrewAI
- Role-based framework: agents as "crews" with specific roles (Researcher, Writer, Reviewer)
- 30,000+ GitHub stars, used for code review and business research
- Both self-organizing and scriptable flows

### AG2 (AutoGen 2025 evolution)
- Event-driven, full asynchronous event logic
- "Everything is a conversation" philosophy
- Specialized agents solve problems through collaborative dialogue

### Google ADK (Agent Dev Kit)
- Modular kit for hierarchical multi-agent systems
- Session management and memory abstractions that persist across interactions

### Dify
- Low-code visual platform with built-in RAG, ReAct, function calling
- Supports 100+ LLMs, good for non-coding experts

### OpenAgents
- Web interface with Data Agent (Python/SQL), Plugins Agent (200+ tools), Web Agent (browsing/forms)

## Selection Criteria
1. Capabilities needed (research vs orchestration vs engagement)
2. Team skillset (code-heavy vs visual/low-code)
3. Control requirements (customization, local hosting)
4. Community health (GitHub issues, Discord activity)

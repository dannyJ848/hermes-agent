# Microsoft Agent Framework 1.0 (April 7, 2026)

## Summary
Microsoft shipped Agent Framework 1.0 — production-ready unification of Semantic Kernel + AutoGen into a single open-source SDK. First major framework with full MCP + A2A support.

## Key Features
- Full **MCP support** for tool discovery and invocation
- **A2A 1.0 support** arriving imminently for cross-framework agent collaboration
- **Browser-based DevUI debugger** — visualize agent execution, message flows, tool calls in real time
- Stable APIs with long-term support commitment
- Enterprise-grade multi-agent orchestration out of the box

## Significance
- Most concrete evidence that **MCP+A2A is the production-ready default** architecture
- Architecture pattern: MCP = resource layer (tools/data), A2A = networking layer (inter-agent coordination)
- MCP v2.1 now at **97 million monthly SDK downloads** — adopted by all major AI providers
- **MCP v2.1 adds Server Cards** — structured metadata via `.well-known` URL for discoverability without connecting
- Linux Foundation's **Agentic AI Foundation (AAIF)** now permanent governance home for both MCP and A2A

## Implications for Hermes Agent
- MCP+A2A becoming the standard; Hermes' skill + CLI approach may need interoperability
- Server Cards enable auto-discovery of tool capabilities — replacing hardcoded configs
- Multi-agent patterns (MCP for tools, A2A for agent-to-agent) gaining production validation
